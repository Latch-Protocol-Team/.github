# .github

Organisation-wide defaults for Latch Protocol: the [profile](profile/README.md) shown on
https://github.com/Latch-Protocol-Team and the issue forms under `.github/ISSUE_TEMPLATE`.

Brand assets in `profile/assets` are the protocol's own (see the brand kit on the site,
`/brand`); the "Powered by Latch" badge may be used by anything built on Latch.
